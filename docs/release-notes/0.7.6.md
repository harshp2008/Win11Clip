## What's new

- **Start at login is now ON by default.** You can turn it off in the Setup Wizard (step 3) or later in Settings, with the new "Start at login" switch.
- The app now has its own app id, so the popup can be found and placed at your cursor more reliably.

## What changed

- **The app is now called Win11Clip.** The command is `win11clip` and the package is `win11clip`.
- Your old data is safe. If you used an older version, its data folders (history, settings, GIF cache) are **copied once** to the new names. Nothing is deleted or moved.
- Your old startup entry and old shortcuts are carried over. They are not duplicated.
- Release files are now named `win11clip_<version>_<arch>` instead of `win11-clipboard-history_...`.

## What was fixed

- A clipboard window no longer pops up at the top left of the screen on your first login after an install.
- The uninstaller now leaves nothing behind. It tells you what it kept (your data) and how to delete it. It removes itself last.
- Automatic checks on GitHub (code style and build) were failing. They pass again. This does not change how the app behaves.
- The Start at login choice is remembered. If the startup entry goes missing and you did not turn it off, it is put back when the app starts.

## Known issues and upgrading

- **After an in-place upgrade, log out and back in once.** A clean install is not affected.
- Releases up to 0.7.5 used the same package maintainer as the upstream project. The installer shows you the maintainer instead of guessing which package is yours.
- Other known issues: details not recorded.
