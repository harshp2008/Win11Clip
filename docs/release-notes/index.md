# Release notes

Newest first. Each file says what is new, what changed, what was fixed, and what to know when upgrading.

- [0.7.6](0.7.6.md) - Start at login is on by default, the app is renamed Win11Clip, and the uninstaller leaves nothing behind.
- [0.7.5](0.7.5.md) - Fixes a clash with the IBus emoji shortcut and the popup showing the wrong tab.
- [0.7.4](0.7.4.md) - Packaging fixes: one spawn-at copy (0.2.4), a cleaner `.deb`, and Arch safety.
- [0.7.3](0.7.3.md) - Cursor placement on Wayland, a self-contained installer, and many popup fixes.
