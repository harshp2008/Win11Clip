## What changed

- This release shipped under the old name, win11-clipboard-history.
- The installer now keeps one copy of spawn-at, and uses spawn-at 0.2.4. Version 0.2.4 is now the minimum.
- The app and the installer now choose the same spawn-at command for the shortcut.
- On Arch Linux, the installer no longer installs the upstream project's AUR package. The package file now points at this project.
- The `.deb` package lists what it needs in a cleaner way.

## What was fixed

- Stopping the app (during uninstall or update) now finds it by its exact name. Before, it could miss it.
- Duplicate libraries in the `.deb` requirements are gone.

## Known issues and upgrading

- On Wayland, a new or updated GNOME extension only loads after you log out and back in. If you installed by hand, install spawn-at 0.2.4 or newer yourself.
